# ✦ Atmosphere — Fluent Acrylic Weather

A high-performance, glassmorphic weather client inspired by Rocksdanister's Windows Weather interface. Powered by Next.js, Tailwind CSS, Lucide icons, and Open-Meteo's zero-config weather and geocoding engine.

---

## ⚡ Features

- **Acrylic Fluent UI**: Frosted glass surfaces, custom sliders, and subtle ambient gradients.
- **Instant Geocoding**: Search any city worldwide with automatic coordinate resolution.
- **Hourly Scrubber**: Interactive 24-hour horizontal forecast cards with rain probability.
- **7-Day Outlook**: High/low temperature spreads and weather status indicators.
- **Telemetry Grid**: Real-time atmospheric metrics including humidity, wind heading, barometric pressure, UV levels, sunrise, and sunset.
- **Zero API Key Required**: Built on top of Open-Meteo.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS + Custom Backdrop Acrylic Filters
- **Icons:** Lucide React
- **Data Source:** Open-Meteo REST API
